# Метрики эталонной проверки качества DXA

**Источник:** локальный `dxa_qc_with_models.zip`, SHA-256 `2cd75f3777a4a7735d8e36cca371d4637b54053fb9283863c64c7214535a8867`; сохранённые решения полного `QCPipeline.infer` с автоматической маршрутизацией. Это **описательные результаты на обучающем/development-наборе**, а не независимая, out-of-fold или клиническая валидация. Модели и пороги могли видеть эти изображения. Приведённые интервалы отражают вариацию при пересэмплировании набора, **не** неопределённость качества на новых пациентах.

Обработано 255 нативных DICOM; 249 имеют экспертный бинарный итог, 6 не размечены и исключены из QC-метрик. Положительный класс — **нарушение качества**. Для каждой задачи `N` — число размеченных изображений; группы частично пересекаются, поэтому их нельзя суммировать. `TP/FP/FN/TN` относятся к положительному классу. `Macro-F1` — среднее F1 положительного и отрицательного классов; `BA` — средняя чувствительности и специфичности.

**Интервалы:** percentile bootstrap, 2000 повторов, seed `20260928`; ресэмплируются с возвращением **целые исследования** по `study_id`, сохраняя все их снимки. Для F1 число определённых повторов — 2000/2000, кроме позиционирования позвоночника (1997/2000) и охвата бедра (1999/2000). Вырожденные повторы без определённого знаменателя исключаются из соответствующего интервала. ROC AUC вычисляется только по непрерывной оценке отдельной задачи при наличии обоих классов (связанные оценки получают половинный вес): для охвата бедра определено 1997/2000 повторов AUC, для позиционирования позвоночника — 1997/2000. Итоговое OR выдаёт только булево решение: общей числовой оценки нет, **AUC для OR не определено**. Dice/IoU не вычислялись: анатомической сегментации нет.

**Анализ ошибок:** итоговое OR ошибается в 24 случаях ложной тревоги и 5 пропусков; для бедра — 17/4, для позвоночника — 7/1. Наиболее слабый F1 отдельной задачи — ось позвоночника (8 FP, 2 FN при 10 положительных случаях). В бедренной проверке позиционирования/ротации 20 FP и 2 FN; малое число нарушений охвата (7) даёт широкий интервал F1. Идеальная оценка артефактов на этих 99 снимках не подтверждает обобщение: соответствующий классификатор обучен на всех размеченных снимках этой группы.

**Сравнение версий:** в исходном отчёте `comparison_to_previous_integration.available=false`; сравнение с hip v10/v13 или независимый head-to-head на одних и тех же размеченных исследованиях не проводились. Отдельный архив hip v13 не смешивался с финальным эталоном. В будущей оценке потребуются независимые исследования и заранее фиксированные пороги; здесь нельзя делать вывод о превосходстве модели или клинической пригодности.

Повторить расчёт локально (Python-окружение backend с установленными зависимостями, запуск из `backend/`):

```bash
PYTHONPATH=../scripts .venv/Scripts/python ../scripts/metrics.py "/path/to/dxa_qc_with_models.zip" --repeats 2000
```

Вывод команды содержит только агрегаты; полный ZIP, строки `per_image`, DICOM и изображения не публикуются.
