# Глоссарий

<p class="lead">Термины и сокращения, которые встречаются в документации и интерфейсе DEXQ.</p>

## Медицина и данные

| Термин | Что это значит |
| --- | --- |
| **DXA** | Двухэнергетическая рентгеновская абсорбциометрия (денситометрия): снимок для измерения плотности костей |
| **DICOM** | Стандартный формат медицинского снимка: изображение плюс служебные поля (теги) |
| **UID** | Уникальный номер в DICOM: исследования (StudyInstanceUID) и снимка (SOPInstanceUID) |
| **Исследование** | Один визит пациента на денситометрию; в нём 1–3 снимка |
| **ROI** | Область интереса: участок бедра, по которому аппарат считает плотность кости |
| **Th12** | 12-й грудной позвонок; снимок поясницы должен захватывать его середину |
| **Ротация бедра** | Поворот ноги при укладке; её признак — насколько виден малый вертел |
| **AP / PA** | Проекция снимка: луч идёт спереди назад / сзади вперёд |
| **MONOCHROME2** | Тип DICOM-изображения в оттенках серого: чем больше значение, тем светлее |
| **PACS** | Система хранения и передачи медицинских снимков в клинике |
| **ТЗ** | Техническое задание организаторов хакатона |
| **ЦДиТ** | Центр диагностики и телемедицины — постановщик задачи |

## Модели

| Термин | Что это значит |
| --- | --- |
| **ML** | Машинное обучение: модель учится на размеченных примерах, а не по заданным вручную правилам |
| **Нейросеть** | Модель, которая превращает снимок в набор чисел — признаков |
| **Замороженная сеть** | Готовая сеть, веса которой мы не меняли; обучались только простые модели поверх |
| **ResNet18** | Распространённая публичная нейросеть для изображений (18 слоёв); у нас извлекает признаки |
| **SpineNet** | Нейросеть, которая находит центры позвонков на снимке |
| **LR** | Логистическая регрессия: простая модель «признаки → вероятность нарушения» |
| **Роутер** | Первая модель: по самому изображению решает, позвоночник это или бедро |
| **Скор (score)** | Число, которое выдаёт проверка; выше порога — нарушение |
| **Эвристика** | Правило, заданное вручную, а не обученное; точность не гарантирована |
| **ONNX** | Открытый формат файлов нейросетей; ONNX Runtime — программа, которая их запускает |
| **NPZ** | Файл с коэффициентами логистических регрессий |
| **Letterbox** | Вписывание снимка в квадрат с чёрными полями без искажения пропорций |

## Оценка качества

| Термин | Что это значит |
| --- | --- |
| **CV** | Кросс-валидация: данные делятся на 5 частей (фолдов), каждая по очереди служит проверочной |
| **Групповая CV** | Все снимки одного исследования попадают в одну часть — модель не видит соседние снимки |
| **TP / FN** | TP — нарушение найдено; FN — пропуск: нарушение есть, но не найдено |
| **FP / TN** | FP — ложная тревога: норму назвали браком; TN — норма верно признана нормой |
| **Чувствительность** | Доля найденных нарушений: TP / (TP + FN) |
| **Специфичность** | Доля норм, признанных нормой: TN / (TN + FP) |
| **F1** | Баланс между долей верных тревог и чувствительностью; 1 — идеально, 0 — ничего не найдено |
| **Macro-F1** | Среднее F1 для двух классов: «нарушение» и «норма» |
| **BA** | Сбалансированная точность: среднее чувствительности и специфичности |
| **ROC AUC** | Шанс, что снимок с нарушением получит скор выше нормального; 0,5 — наугад, 1 — идеально |
| **ДИ** | 95% доверительный интервал: диапазон, где с вероятностью ≈95% лежит истинное значение |
| **Бутстреп** | Способ посчитать ДИ: 2000 раз пересобираем выборку из исследований и пересчитываем метрику |
| **OR** | Логическое «ИЛИ»: итог — нарушение, если сработала хотя бы одна проверка |

## Программа и запуск

| Термин | Что это значит |
| --- | --- |
| **API** | Интерфейс для других программ: запросы по HTTP, ответ в JSON или CSV |
| **GET / POST** | Типы HTTP-запросов: получить данные / отправить файлы на анализ |
| **CLI** | Запуск из командной строки, без браузера и сервера |
| **CSV / XLSX** | Таблица в текстовом виде / файл Excel |
| **JSON** | Текстовый формат структурированных данных |
| **ZIP** | Архив с несколькими файлами |
| **CPU / GPU** | Центральный процессор / видеокарта; DEXQ работает только на CPU |
| **ОЗУ (RAM)** | Оперативная память |
| **VM** | Виртуальная машина: отдельный компьютер, запущенный программно |
| **Docker** | Контейнеры: программа со всеми зависимостями запускается одинаково на любой машине |
| **SHA-256** | Контрольная сумма файла: меняется при любом изменении, так проверяем веса |
| **H200** | Видеокарта NVIDIA на целевой машине организаторов; DEXQ её не использует |
| **МиБ / ГБ** | Единицы объёма данных: мебибайты и гигабайты |
