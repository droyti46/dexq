## Цель
Спокойный профессиональный интерфейс для локального контроля качества DXA. Без новых зависимостей, UI-kit, серверного хранения и внешней передачи медицинских данных. Evolventa / Evolventa Bold сохраняются.

## Визуальная система
Уточнение пользователя: лендинг и публичные страницы сохраняют исходную ярко-синюю тему. Графитовая тема применяется только к списку проектов и workspace.
Графитовый фон #191b1e, панели #222529, поднятые поверхности #2c3035, границы #3b4047, основной текст #edf0f2, вторичный #a8adb5. Приглушённый синий #92accb только для фокуса и активных инструментов; зелёный/красный только для результатов. Центральное поле просмотра почти чёрное. Обложки проектов — стопки реальных локальных превью, без фиктивных медицинских результатов.

## Навигация и данные
Главная → /projects → /projects/:projectId. /analyze и /result направляют в список проектов. В верхней панели workspace только логотип и Файл / Правка / Редактор. Возврат в проекты — в левой панели. Список: сетка карточек, имя, время, количество снимков; создание проекта в диалоге с именем.

Проекты, исходные File, результаты и ручные оси находятся в памяти React на уровне приложения. Навигация не прерывает очередь. Закрытие или перезагрузка вкладки очищает проекты; интерфейс сообщает об этом. Никакого localStorage/IndexedDB для медицинских изображений. Исходный результат автоматической проверки не изменяется ручной осью.

## Снимки
Добавление через input и drop в левой панели или viewer дополняет проект. До 200 снимков в проекте; DICOM/PNG/JPEG либо отдельный ZIP. Ошибка формата не стирает существующие данные. Анализ последовательный, ZIP потоковый; состояние и ошибки для каждого файла. Пауза — после текущего файла. Очередь продолжает работу при возврате к проектам.

Просмотр и выделение разделены: обычный клик открывает снимок и выделяет его; checkbox/Ctrl/Cmd переключают выделение; Shift выделяет диапазон. Действия: выбрать все, снять выделение, удалить выбранные с подтверждением. Удаление очищает превью и ручные оси; ответ незавершённого запроса не восстанавливает удалённый объект.

## Меню и viewer
Файл: новый проект, открыть проект/список, добавить снимки, экспорт CSV, выйти к проектам. Правка: удалить выбранные, выбрать все, снять выделение. Редактор: увеличить, уменьшить, вписать, сбросить вид, показать/скрыть overlay. Disabled для недоступных действий. Меню имеют keyboard navigation, Esc, закрытие снаружи.

Viewer: drag на фоне/снимке перемещает; средняя/правая кнопки перемещают в любом режиме и не редактируют точки. Wheel zoom относительно курсора, пределы 25–800%, без прокрутки страницы. Fit возвращает масштаб 100% относительно вписанного изображения и центр; reset также возвращает яркость/контраст и включает overlay по умолчанию. Отдельный переключатель overlay скрывает и геометрические ориентиры. Подсказка управления, текущий масштаб, доступные названия инструментов. Ручная ось редактируется только основной кнопкой в режиме выбора; исходная автоматическая оценка неизменна.

CSV и Excel .xlsx экспортируются локально без повторного анализа: одна строка на завершённый файл, стабильные восемь колонок API, корректные кавычки и защита от spreadsheet formula injection. Выделенные файлы могут экспортироваться отдельно. Незавершённые файлы не выдаются за готовый отчёт.

## Проверка
Node test runner для состояния проектов, добавления/удаления, лимитов, выделения, CSV и преобразования координат zoom. npm run build. pytest и ruff check . для существующих backend-правок без изменения медицинской логики. В браузере: главная, проекты, создание/открытие/возврат, меню и клавиатура, append/drop, выделение/удаление во время анализа, viewer/wheel/right/middle drag/overlay/reset, узкий экран, console/network и снимки экрана.
