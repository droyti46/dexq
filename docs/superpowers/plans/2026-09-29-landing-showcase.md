# Landing Showcase Implementation Plan

**Goal:** Добавить согласованный белый блок с реальными скриншотами DEXQ и описаниями возможностей.
**Architecture:** Статические локальные WebP-скриншоты текущего интерфейса; CSS-композиция перекрывающихся снимков, без UI-kit/зависимостей. Блок внутри существующей LandingPage после синего видео и перед полосой возможностей.
**Spec:** Пользователь согласовал композицию 2026-09-29 и разрешил использовать имеющиеся изображения. Внешние сервисы не используются; личные имена/UID исключены из публичных скриншотов, медицинские исходники не копируются в assets.

## Визуальная система
Белый #fff, фирменный синий #0202f1, основной текст #12142c, вторичный #71758d, мягкая подложка #f2f3ff. Evolventa/Bold. Один большой накладывающийся коллаж workspace + projects + фрагмент QC, тонкие синие рамки, скругления, разные уровни тени. Без подмены реальных результатов/клинических заявлений.
