# Сохранение ручной оси

**Запрос:** инструмент «Редактировать ориентиры» по умолчанию, кнопка «Сохранить», экспорт ручных корректировок. Проекты по согласованию остаются только в текущей вкладке.

## Реализация
- [x] Черновая ось и история остаются в `Project.manualAxes` / `axisHistories`; сохранённая копия — в `WorkspaceItem.savedAxis`. Кнопка сохранения применяется к текущему снимку, сброс также требует сохранения.
- [x] Исходный `AnalysisResult` не изменяется. Сохранённая ручная ось заменяет только `spine_axis`; угол выше 5° отмечается как эвристическое нарушение, остальные проверки сохраняются. Исходный автоматический класс показан рядом.
- [x] CSV и Excel используют одинаковую таблицу с сохранённой оценкой. При наличии ручной оси добавляются источник, координаты, угол и правило; без ручных правок сохраняются исходные 8 колонок. Несохранённые правки препятствуют тихой выгрузке устаревшей оценки.
- [x] Проверить default tool, drag, Save, export блокировку черновика, CSV/XLSX, undo, reset и переходы между проектами.
- [x] Обновить руководство; исходные DICOM и временные выгрузки не добавлять в репозиторий.

## Проверка
Новые тесты расчёта/экспорта сначала показали неправильный класс, игнорирование сохранённой оси и отсутствие provenance. После реализации весь frontend suite: 33 passed. Production build выполнен успешно.

Локальный browser smoke: реальный обезличенный снимок, перенос нижней точки на вертикаль, сохранение: класс 1 → 0 только по ручной эвристике; оригинал класса 1 остался видимым. CSV и скачанный Excel содержат координаты, угол и `manual_axis_heuristic`. Повтор/отмена, сохранение сброса и переход в список/назад проверены. Никаких внешних сервисов, новых API или постоянного хранилища.
