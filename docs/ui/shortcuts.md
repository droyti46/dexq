# Горячие клавиши

На macOS вместо ++ctrl++ используйте ++cmd++.

## Ось позвоночника

| Клавиши | Действие |
| --- | --- |
| ++ctrl+z++ | Отменить правку оси |
| ++ctrl+y++ / ++ctrl+shift+z++ | Повторить правку оси |
| ++arrow-up++ ++arrow-down++ ++arrow-left++ ++arrow-right++ | Сдвинуть выбранную точку оси на 1 пиксель |

## Список снимков

| Клавиши | Действие |
| --- | --- |
| ++ctrl++ + клик | Добавить снимок в выделение или убрать из него |
| ++shift++ + клик | Выделить диапазон снимков |
| ++del++ | Удалить выбранные снимки (с подтверждением) |

## Просмотрщик

| Мышь | Действие |
| --- | --- |
| Колесо | Масштаб относительно курсора |
| Перетаскивание (инструмент «рука»), правая или средняя кнопка | Сдвинуть изображение |
| Двойной клик | Вписать снимок в окно |

## Меню и панели

| Клавиши | Действие |
| --- | --- |
| ++arrow-down++ на названии меню | Открыть меню |
| ++arrow-up++ ++arrow-down++ ++home++ ++end++ | Перейти по пунктам меню |
| ++arrow-left++ ++arrow-right++ | Перейти к соседнему меню |
| ++esc++ | Закрыть меню |
| ++arrow-left++ ++arrow-right++ на разделителе панелей | Изменить ширину панели на 20 пикселей |
| ++home++ на разделителе | Вернуть ширину по умолчанию |
